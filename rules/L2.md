# L2 — No original game data in the repository
id: L2 · group: L · status: active · tags: legal, git, data · origin: README (pre-PA3) · added: 2026-11-22

## Text

The repository never contains original game data: no disc images, DOL/REL files, extracted textures, symbol maps (`analysis/symbols*.txt`, `analysis/rel-symbols/`), saves or FIFO captures (`*.dff`). Each developer supplies their own legally obtained GYWEE9 dump; derived inputs are regenerated locally and stay gitignored (`.gitignore`). Source: `README.md` Reproducing locally and Legal.
